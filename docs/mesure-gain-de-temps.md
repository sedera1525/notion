# Mesure du gain de temps

## Tableau à remplir

Remplir les deux colonnes en minutes, pour un même rapport.

| Étape | Temps manuel estimé | Temps avec automatisation |
|---|---|---|
| Lecture du rapport | | |
| Rédaction de la synthèse | | |
| Mise en forme dans Notion | | |
| Relecture | | |
| **Total** | | |

## Calcul du pourcentage de gain

```
Gain (%) = (Total manuel − Total automatisé) ÷ Total manuel × 100
```

Exemple de lecture de la formule : si le total manuel est de 60 minutes et le total
automatisé de 15 minutes, le gain est de (60 − 15) ÷ 60 × 100 = **75 %**.

Le temps économisé en valeur absolue est parfois plus parlant qu'un pourcentage :

```
Temps économisé = Total manuel − Total automatisé
```

## Comment mesurer sans se tromper

1. Utiliser **le même rapport** pour les deux colonnes. Comparer deux rapports
   différents fausse le résultat.
2. Chronométrer, ne pas estimer de mémoire.
3. Faire le passage manuel **en premier**. Si la synthèse automatique a déjà été lue,
   le travail manuel est artificiellement accéléré.
4. Compter dans la colonne « automatisation » tout le temps réellement passé :
   le lancement, l'attente, **et la relecture de contrôle**. La relecture reste
   nécessaire : c'est elle qui rend le résultat utilisable.
5. Refaire la mesure sur deux ou trois rapports si possible, et donner une fourchette
   plutôt qu'un chiffre unique.

## Avertissement

Les temps inscrits dans ce tableau sont ceux que **je mesure moi-même, sur ce cas
fictif**. Ce ne sont pas des résultats d'étude, ni une garantie de performance.

Ils dépendent de la longueur du rapport, de sa structure, de la qualité du document
source et de l'habitude de la personne qui réalise le travail manuellement. Un gain
mesuré ici ne se transpose pas tel quel à un autre contexte.
